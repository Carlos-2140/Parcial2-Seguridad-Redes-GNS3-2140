# Evidencias originales

Archivos PNG originales compartidos durante el segundo parcial, sin alteración de su contenido:

- `VPN/`: estados y políticas de FortiGate.
- `Zabbix/`: host, disponibilidad SNMP y últimos datos.
- `Windows-Server/`: quince capturas auténticas (WS-01 a WS-15).
- `Evidencias_Windows_Server_AD_NPS_Sin_Fuentes.docx`: informe original de las capturas de Windows.

La topología está en `../Topologia/Topologia.png`.

**Nota:** la ausencia de otras capturas en este paquete no implica que esas pruebas no se hayan realizado. Para cada requisito que lo demande, incorporar una captura real del equipo antes de entregar.
